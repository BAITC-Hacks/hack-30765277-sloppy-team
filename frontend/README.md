# Практика — фронтенд

Next.js App Router, React и TypeScript. [Полная инструкция пилота](../PILOT_GUIDE.md)
содержит запуск двух сервисов и сценарии бизнеса и студента.

```powershell
npm ci
$env:BACKEND_URL = "http://127.0.0.1:8000"
npm run dev
```

Python-бэкенд должен работать отдельно. Next.js вызывает его с сервера; ключ
OpenAI хранится только в окружении Python. Для режима без ключа запустите Python
с `AI_MODE=demo`. Браузер работает с `/api` того же сайта.

- `/catalog` — открытый каталог с сортировкой и фильтрами, включая статус DRAFT.
- `/create-task` — черновик, три уточнения, карточка, рейтинг, подтверждение.
- `/tasks/[id]` — отклик студента или редактирование карточки бизнесом.
- `/my-tasks` — общий демонстрационный кабинет.
- `/my-tasks/[id]/apps` — ручное принятие или отклонение; можно выбрать несколько команд.

Это не авторизация: кабинет общий. Прежнее локальное хранилище `.data/store.json`
используется без изменения реализации и рассчитано на один процесс.

Проверки:

```powershell
npm test
npm run typecheck
npm run build
```

Интеграционный тест сам запускает Python в `AI_MODE=demo` на свободном порту и
создаёт изолированную временную папку для существующего демохранилища. Нужны
зависимости Python в `backend/.venv` или корневой `.venv`; другой интерпретатор
можно указать переменной `PYTHON`. Реальные пользовательские записи тест не меняет.

Контракты, формула и обработка ошибок: [архитектура](../ARCHITECTURE.md).
